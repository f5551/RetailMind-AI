تحليل بيانات مبيعات التجزئة بدقة استدلالية وأمان صارم

RetailMind AI هو وكيل استدلال فردي (Single Reasoning Agent) مبني لتحليل ملفات مبيعات التجزئة CSV. يربط نماذج Google Gemini (`gemini-3.1-flash-lite`) ببروتوكول سياق النموذج الرسمي (Model Context Protocol - MCP)، ويقدم تحليلات مالية دقيقة، وكشفاً للأنماط الشاذة، وتوليد تقارير محكومة بموافقة بشرية صريحة.

ركائز المعمارية والحوكمة

🧠

وكيل استدلال فردي وحقيقي

حلقة استدلال حقيقية تستدعي الأدوات ديناميكياً عبر Gemini API (`google-genai`). آلية إيقاف ثلاثية صارمة: الحد الأقصى للجولات (8 جولات)، وسقف التكلفة ($0.10)، والإجابة النهائية للنموذج.

🔌

بروتوكول MCP القياسي

ربط 8 أدوات برمجية دقيقة عبر خادم وعميل MCP رسمي (`mcp==2.3.0`) يعمل عبر subprocess وstdio، مع عزل كامل لمعاملات الجلسات ومطابقة الهوية الموثوقة.

🛡️

أمان صارم وتفويض كتابة

سياسة `ask_on_write`: التحليل المالي يعمل تلقائياً، بينما توليد التقارير وتصديرها يتطلب موافقة بشرية صريحة محكومة بكود برمجي عبر تذاكر مشفرة في SQLite وسجل تدقيق غير قابل للتعديل.

💾

ذاكرة SQLite المستدامة

تخزين دائم للسياقات التحليلية وسجلات التدقيق في SQLite WAL، مع إثبات تعافي الذاكرة واستعادتها بنجاح تام بعد إعادة تشغيل العملية بالكامل.

أدوات التحليل الثمانية (MCP Tools Contract)

أدوات حسابية قطعية خالية من أي هلوسة أو استنتاجات غير مثبتة

الأداة النوع والترخيص الوصف الوظيفي والناتج الحسابي
inspect_dataset Read / Auto فحص بنية الملف، أسماء الأعمدة، عدد السجلات الصالحة، وفحص سجلات الحجر الصحي.
validate_dataset Read / Auto تدقيق نطاقات الأسعار والكميات، رصد الصفوف المكررة، والتأكد من سلامة المعاملات.
summarize_sales Read / Auto احتساب صافي الإيرادات مجموع(الكمية × السعر)، وإجمالي الأرباح، ونسبة هامش الربح الإجمالي بدقة.
rank_products Read / Auto ترتيب المنتجات تصاعدياً أو تنازلياً حسب الإيرادات والكميات، وحصة كل منتج من المبيعات.
compare_periods Read / Auto مقارنة فترتين زمنيتين، رصد تباين التكاليف، واحتساب معدل النمو النسبي بدقة صفرية.
detect_anomalies Read / Auto كشف القيم المتطرفة إحصائياً باستخدام أسلوب المدى الربيعي الديناميكي (Dynamic IQR).
segment_sales Read / Auto تجزئة المبيعات والإيرادات حسب الفئة أو المنطقة أو مجموعات المنتجات الفرعية.
generate_report Write / Approval Required صياغة تقرير مالي وتنفيذي وتصديره إلى صيغة Markdown محكمة؛ يستلزم موافقة المستخدم الصريحة.

دليل التشغيل المحلي ووثائق المشروع

روابط ومستندات الحوكمة الرسمية في المستودع

تشغيل الوكيل كاملاً على جهازك المحلي عبر Python:

# استنساخ المستودع وتثبيت البيئة
git clone https://github.com/f5551/RetailMind-AI.git
cd RetailMind-AI
python -m venv .venv
source .venv/bin/activate       # وفي نظام Windows: .venv\Scripts\activate
pip install -r requirements.txt

# ضبط المفاتيح والتشغيل
cp .env.example .env            # أضف مفتاح GEMINI_API_KEY
streamlit run app.py            # واجهة SaaS ثنائية اللغة على http://localhost:8501
