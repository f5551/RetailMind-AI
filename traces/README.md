# RetailMind AI — Execution Traces Directory

This directory stores authentic JSONL execution traces generated by the agent loop during actual runs.

Per **CAPSTONE_REQUIREMENTS.md**, the final submission requires three genuine trace files at these exact paths:
1. `traces/success_1.jsonl` — A successful end-to-end task execution demonstrating multi-turn reasoning and tool calls.
2. `traces/near_failure_recovery.jsonl` — A task where a tool failed, returned unexpected output, or encountered an issue, and the agent successfully recovered.
3. `traces/explicit_failure.jsonl` — An authentic, unrecovered failure (e.g. budget exceeded, unrecoverable data error, or hard tool failure), documenting the diagnostic outcome honestly.

> **CRITICAL RULE**: Do NOT fabricate, invent, or pre-populate fake traces. Traces must be saved from genuine live executions during Phase 2 and Phase 4.
